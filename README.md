# Феникс — версия V17 Desktop Structure

Изменения:
- Главная кнопка «Принять участие» прокручивает к «Ближайшим событиям».
- Убраны четыре нижние плашки первого экрана.
- Регистрация открывается только из конкретной карточки события.
- Вид спорта участник не выбирает: он подставляется автоматически из события.
- В форме показываются название, дата, время и место выбранного события.
- Видеословарь вынесен на отдельную страницу `dictionary.html`.
- Главная стала короче: первый экран → о проекте → события → предложения → контакты.

Важно по таблицам:
Текущий Apps Script endpoint сохранён, поэтому заявки продолжают отправляться в существующую таблицу. Для физически отдельных Google-таблиц по каждому событию нужны отдельные Apps Script endpoints (или один обновлённый скрипт, который маршрутизирует заявки по листам/таблицам). Код формы уже передаёт `sport` и `event`, поэтому следующий этап можно подключить без возврата выбора вида спорта пользователю.

Форма предложений пока сохраняет текущую отправку через e-mail. Для Google-таблицы предложений потребуется endpoint отдельной таблицы/скрипта.

Правка 24: плавная волнистая граница HERO → О проекте; декоративное изображение/элементы настольного тенниса удалены.
